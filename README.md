## 🚧 Featured project

### [SupermarketPriceTracker](https://github.com/EvaBraga/SupermarketPriceTracker) · in development since August 2026

A Java system to record and compare grocery prices across supermarkets.

-   Products organized by category (enum) and sorted by price with a custom comparator
-   Monetary values handled with `BigDecimal` to avoid rounding errors
-   Automated tests with JUnit 5

**Next steps:** database persistence and web scraping with Python.
